# Start here
Before working, read **STATUS.md** (current project state, what is done vs open, the
TODO backlog, working constraints, and the handoff for a second machine) and
**CALENDAR_MAP.md** (the availability/calendar system: functions, dependency map, the one
invariant, change-checklist). Keep STATUS.md updated and pushed to `main` after meaningful
changes, so another machine picking up this repo stays in sync. Local assistant memory does
not travel across machines; these two files are the shared source of truth.
